# You Won!

...or did you? Find out today.

## Try it yourself

```bash
npm install
npm run build
```

Then open `dist/index.html` directly in your browser: double-click it, or drag it
into a window. 

Needs Node 22 or newer.

## Run the tests

```bash
npm test
```

Note that `npm test` rebuilds `dist/index.html` as a side effect, because the
build tests run the real bundler.

## Deploy

Hosted on Vercel. `vercel.json` has everything: it runs `npm run build` and
serves `dist/`, so the deployed app is always built from the source that was
pushed rather than from a committed artifact that might be stale.

```bash
vercel --prod
```

The built file carries its own Content-Security-Policy, generated by the build
and pinned by hash to the exact script it produced. If you hand-edit
`dist/index.html`, the browser will refuse to run it until you rebuild. That is
the intended behaviour, not a bug.
